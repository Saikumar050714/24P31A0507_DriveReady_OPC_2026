## Task 1: Basic LLM Interaction

The notebook initializes the Groq chat model with `ChatGroq`:

```python
from langchain_groq import ChatGroq

llm = ChatGroq(
    model="openai/gpt-oss-120b",
    temperature=0
)

resp = llm.invoke("What is Artificial Intelligence?")
print(resp.content)
```

The `invoke()` method sends a prompt to the model, and `resp.content` prints the generated answer.

## Task 2: Sweet Crumbs Home Bakery Chatbot

### Bakery menu

The chatbot uses the following menu and prices supplied in the task:

| Item | Price |
|---|---:|
| Plum cake | 500 |
| Chocolate cake | 650 |
| Cupcake | 80 |

### Chatbot rules

The system prompt instructs the assistant to:

- Be polite and concise (under 60 words).
- Require 24 hours' advance notice for orders.
- State that eggless options are available.
- Never promise delivery times unless they are confirmed.
- Use only the supplied menu and prices.
- Never invent menu items or prices.

### How the chatbot works

1. The `bakery_chat(question)` function receives a customer's question.
2. It creates a `SystemMessage` containing the bakery instructions and menu.
3. It creates a `HumanMessage` containing the customer's question.
4. It sends both messages to the Groq model using `llm.invoke(messages)`.
5. It returns the model's response text.

### Test questions

The notebook tests the chatbot with these questions:

- What is the price of a chocolate cake?
- Do you have eggless cakes?
- How much notice should I give before ordering?
- Can you guarantee delivery at 5 PM?

The responses should follow the supplied menu and rules. Exact wording may vary because the answers are generated by the LLM.
